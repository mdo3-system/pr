2. プログラムの利用目的・背景

本システムは、建築士事務所や工務店等の取引先・会員企業向けに業務支援及び管理を行うWebプラットフォームです。
インボイス制度（適格請求書等保存方式）に準拠した適正な取引・請求業務を推進するため、登録された取引先企業や新規登録企業の適格請求書発行事業者番号（登録番号）および公表情報の有効性を国税庁Web-APIを通じて自動照会・検証し、請求書発行・受取業務における税務コンプライアンスの担保および事務処理の効率化を図ることを目的とします。

3. システム構成及び電子計算機環境

サーバー環境 クラウドWebサーバー（Linux / Apache・PHP 8.x）
データベース MySQL 8.0（SSL/TLS暗号化接続）
通信セキュリティ 常時SSL/TLS（HTTPS）暗号化通信（TLS 1.2 / 1.3）
実行プログラム Web-API通信クライアント（PHP cURL / REST API連携モジュール）

4. 処理フロー及びWeb-APIの利用方法

【処理フロー図】 [管理者 / 取引先企業] │ 企業情報の登録・更新（法人番号・登録番号・企業名） ▼ [本システム（Webサーバー）] │ HTTPS リクエスト（Web-API / JSON or XML） ▼ [国税庁 適格請求書発行事業者公表システム Web-API] │ レスポンス（公表情報：登録番号、法人名、所在地、有効性ステータス） ▼ [本システム（Webサーバー）] │ データの検証・突合（適格請求書発行事業者の有効確認） ▼ [暗号化データベース（MySQL）] へセキュアに保管・管理
  • 取得データ項目: 登録番号、事業者名（法人名・屋号）、本店・主たる事務所の所在地、登録年月日、失効・取消情報等の公表情報
  • 利用方式: 取引先情報登録時の個別API照会、および全件データによる定期的なステータス差分確認・照合

5. データの保存・安全管理体制

  • アクセス制御: システムへのアクセスはID・二要素認証により保護され、権限を持つ正規の管理者および認可ユーザーのみに制限。
  • 通信及びデータの保護: 全ての通信経路はHTTPSにより暗号化。データベースはクラウド上のセキュア領域に配置され、外部からの不正直接アクセスを遮断。
  • バックアップ及びログ管理: データの定期バックアップを実施するとともに、APIアクセス履歴・操作ログを記録・保存し、定期的な監査を実施。

6. 利用者の把握及び管理方法

本システムの利用者は、自社の業務担当者および認証済みの取引先企業に限定されます。ログイン管理およびセッション管理を通じて「いつ」「誰が」「どの情報」を閲覧・処理したかの証跡ログをサーバーに記録し、不正利用や第三者への情報漏洩を防止します。
